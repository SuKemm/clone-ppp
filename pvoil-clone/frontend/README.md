# PVOIL Frontend

This folder contains the frontend clone of the PVOIL website.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`

## Notes

- Use the App Router in `src/app`
- Keep components modular and reusable
- Keep styles in Tailwind CSS with semantic utility classes
- Mirror the original site page-by-page and component-by-component
