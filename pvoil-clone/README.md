# PVOIL Clone

This directory is a dedicated clone project for `https://www.pvoil.com.vn/`.

## Structure

- `frontend/` — Next.js app for the PVOIL frontend clone
- `backend/` — placeholder for future backend services and API integration

## Next steps

1. Build the frontend pages and components to mirror the original PVOIL website exactly.
2. Keep frontend and backend concerns separated for maintainability.
3. Add localization, routing, and data contracts as needed.
